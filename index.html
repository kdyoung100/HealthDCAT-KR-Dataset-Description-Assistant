항목을 채우면 HealthDCAT-KR 명세에 맞는 데이터세트·배포 형식 파일이 만들어집니다. 설치할 것도, 계정도 없습니다. 브라우저에서 열고 바로 씁니다.

메타데이터 생성 시작 → 화면 먼저 보기
01

무엇이 만들어지나

데이터세트와 배포 형식은 서로 다른 클래스이므로 파일 두 개로 나뉘어 나옵니다. 파일 이름에는 데이터셋 이름이 들어갑니다.

HealthDCAT-KR_데이터셋이름_데이터셋.rdf
dcat:Dataset

제목·설명·주제·접근 권한처럼 데이터셋 자체를 설명하는 26개 항목이 담깁니다.

HealthDCAT-KR_데이터셋이름_배포.rdf
dcat:Distribution

CSV·XLSX처럼 실제로 내려받는 파일 형태별 배포본이 담기며, dct:isPartOf로 데이터셋과 이어집니다.

JSON-LD · .jsonld Turtle · .ttl RDF/XML · .rdf
미리보기 · 내려받기 전에 오른쪽 칸에서 세 가지 형식 중 아무거나 골라 결과를 그대로 확인할 수 있습니다. 직접 입력이든 엑셀 일괄이든 똑같이 보입니다.
02

두 가지 작성 방식

한 건이면 직접 입력이 빠르고, 여러 건이면 엑셀이 편합니다. 결과로 나오는 파일은 같습니다.

직접 입력엑셀로 일괄 등록
알맞은 때데이터셋 1건을 꼼꼼히 작성할 때여러 데이터셋을 한 번에 올릴 때
작성 방법항목별 입력 칸에 직접 입력양식(.xlsx)을 내려받아 채운 뒤 올리기
검증항목 단위 — 비어 있거나 형식이 어긋난 칸을 표시행·열 단위 — 오류가 있는 행만 모아 보기
결과 파일데이터셋 1건 → 파일 2개데이터셋 N건 → 이름별로 각각 2개씩
03

화면 보는 법

왼쪽에서 무엇을 쓸지 고르고, 가운데에서 채우고, 오른쪽에서 진행 상황과 결과를 봅니다.

작성 현황의 숫자는 눌러서 펼칠 수 있습니다. 비어 있는 항목이 목록으로 나오고, 누르면 그 칸으로 바로 이동합니다.

필수 · 권장 구분

항목마다 필수 권장 중 하나가 붙습니다. 위쪽 거르기로 필수만 골라 먼저 채우면 빠릅니다.

필수값 검증

비어 있는 필수 항목과 형식이 어긋난 값(URL·이메일)을 빨갛게 표시하고 첫 번째 항목으로 이동합니다.

배포방식 적기

데이터세트의 배포방식 칸에 CSV, XLSX처럼 파일 형태를 쉼표로 적으면 그만큼 배포 건이 준비됩니다.

언어 태그

오른쪽 위 기본 언어에 따라 제목·설명 같은 글 항목에 @ko 또는 @en이 자동으로 붙습니다.

04

엑셀로 여러 건 한 번에

데이터셋 양식과 배포 양식, 두 개의 파일을 씁니다. 두 양식은 데이터셋식별자로 이어집니다.

1

양식 내려받기

데이터셋 양식과 배포 양식을 각각 받습니다. 첫 행은 항목 이름, 둘째 행은 속성명, 셋째 행은 작성 예시입니다. 4행부터 채우세요.

2

채우기 · 두 양식 잇기

데이터셋 양식의 식별자에 적은 값을 배포 양식의 데이터셋식별자에 그대로 적으면 두 줄이 이어집니다.

3

올리고 검증하기

두 파일을 함께 끌어다 놓으면 어느 쪽 양식인지 알아서 구분합니다. 검증하면 오류가 있는 행만 모아 볼 수 있고, 표 보기와 카드 보기를 오갈 수 있습니다.

배포 양식만 올려서 배포 파일만 만들어도 됩니다.

4

내려받기

데이터셋 이름별로 파일이 따로 나옵니다. 3건이면 _데이터셋 3개와 _배포 3개, 모두 6개입니다.

양식식별자 / 데이터셋식별자그 밖의 칸
데이터셋NDI-2024-001제목, 설명, 주제, 접근 권한 …
배포NDI-2024-001접근 URL, 파일 형식 = CSV
배포NDI-2024-001접근 URL, 파일 형식 = XLSX
같은 식별자를 쓴 배포 두 줄은 데이터셋 한 건에 배포 형식 두 개로 묶입니다.
05

항목 구성

데이터세트 26개, 배포 형식 5개 항목입니다.

데이터세트 26개 · 필수 6 / 권장 20

필수 항목은 다음 여섯 개입니다.

제목dct:title 설명dct:description 주제dcat:theme 접근 권한dct:accessRights 식별자dct:identifier 보조식별자adms:identifier

배포 형식 5개 · 필수 1 / 권장 4

접근 URL만 필수입니다.

접근 URLdcat:accessURL 설명dct:description 가용성dcatap:availability 파일 형식dct:format 라이선스dct:license
필수·권장 구분은 HealthDCAT-AP의 제한(Restricted) 권한 기준을 준용합니다. 자세한 근거는 HealthDCAT-KR 프로파일 문서에서 볼 수 있습니다.
06

자주 묻는 것

입력한 내용이 어딘가로 전송되나요?

아니요. 모든 처리는 브라우저 안에서 이루어지고, 만든 파일도 기기에 바로 저장됩니다. 다만 새로고침하면 작성 중인 내용은 사라지니 중간중간 내려받아 두세요.

파일 형태가 CSV와 XLSX 두 가지인데 어떻게 적나요?

배포는 파일 형태 하나당 한 건입니다. 데이터세트의 배포방식 칸에 CSV, XLSX처럼 적고, 데이터 배포방식 화면에서 각 건의 접근 URL을 채우면 됩니다.

배포 양식만 올려도 되나요?

됩니다. 데이터셋식별자별로 묶어 배포 파일만 만들어 줍니다. 식별자가 비어 있는 행은 연결안된배포라는 이름으로 따로 모입니다.

거르기의 ‘선택’이 눌리지 않습니다.

현재 항목은 모두 필수 또는 권장이라 선택에 해당하는 항목이 없습니다. 그래서 눌리지 않도록 두었고, 항목이 추가되면 열립니다.

잘못 올린 엑셀 파일은 어떻게 빼나요?

올라온 파일 이름 오른쪽의 × 를 누르면 빠집니다. 같은 파일을 고쳐서 다시 올리는 것도 됩니다.

파일 이름을 바꿔도 되나요?

됩니다. 이름은 사람이 알아보기 위한 것이고, 데이터 안의 식별자(dct:identifier)와 dct:isPartOf 연결이 실제 기준입니다.

준비되셨나요

필수 여섯 개만 채워도 파일이 나옵니다. 나머지는 채우면서 다듬으세요.
